# CuteFela asset credits

## CuteFela / user-supplied material
Brand marks, school crests, programme photographs, conference photographs, project videos, wildlife-project PDF material and other media supplied for this build are treated as CuteFela/user-supplied assets. Verify publication rights internally before public launch where a third party originally created a file.

## Wildlife Rehabilitation Centre material
The website uses cropped photographic material extracted from the supplied Wildlife Rehabilitation Centre project PDF. Architectural proposal sheets are not displayed as completed construction.

## SDG media
The SDG target media cards included in the supplied SDG archive are used selectively in the Global Goals section. United Nations Sustainable Development Goals marks remain subject to UN usage guidance.

## Global wildlife and nature media
The global and species media library in this build was supplied in the user's uploaded archive sets. File names are preserved only in the working source library; public website filenames are normalised. Where those archive assets were originally sourced from Pexels, Pixabay, Wikimedia Commons or another provider, the underlying licence and creator attribution should be retained in the organisation's source records. The public design intentionally does not place photographer-name badges over imagery when attribution is not required on-image.

## Conference photography
UNFCCC COP28, COP29, UNCCD COP16, UNFCCC COP30, Second World Summit for Social Development Doha 2025, and UNCCD COP17 Ulaanbaatar 2026 photographs were supplied for this build.

## Code libraries loaded from CDNs
- GSAP + ScrollTrigger
- Anime.js
- Motion.dev
- React 18 + ReactDOM
- React Spring

The site keeps core content in static HTML so it remains readable and indexable without these animation libraries.


## Disaster Response media
The Disaster Response page uses only local natural photography and local video files. The emergency response footage, environmental restoration media and CuteFela supplied community learning photographs are stored inside the repository. The page uses ten distinct still images and five distinct videos, with no remote image or video dependency. Environmental and workshop media is used as preparedness, recovery or resilience context and is not presented as evidence of a specific CuteFela disaster deployment.
